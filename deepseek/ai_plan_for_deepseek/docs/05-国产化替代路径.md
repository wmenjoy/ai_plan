### 1. 混合架构支持
```python
# 鲲鹏+GPU混合训练示例
import paddle
from paddle.fluid import core

def set_device():
    if core.is_compiled_with_npu():
        paddle.set_device('npu:0')
    elif core.is_compiled_with_cuda():
        paddle.set_device('gpu:0')
    else:
        paddle.set_device('cpu')

# 自动选择最优后端
set_device()
```
